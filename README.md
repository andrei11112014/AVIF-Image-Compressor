# Краткое описание проекта
Веб-приложение для конвертации изображений в формат AVIF с использованием аппаратного ускорения через кодек AV1.
# Технологический стек
* Frontend: React.
* Backend: Node.js.
* Обработка изображений: библиотека libavif (C/C++).
* Контейнеризация: Docker.
* Почанковая загрузка изображений на сервер.
# Функциональные требования
* Работа в актуальных версиях браузеров:
  * Google Chrome: версия 85+
  * Mozilla Firefox: версия 93+
  * Microsoft Edge: версия 121+
  * Opera: версия 71+
* Работа с форматами PNG, JPEG.
* Загрузка изображений на сервер.
* Возможность сжатия с потерями и без потерь.
* Возможность изменения разрешения загруженного изображения.
* Возможность загружать и сжимать несколько изображений за раз. 
* Предпросмотр готового результата.
* Сохранение сжатых изображений на устройство пользователя.
# Пользовательские возможности
Пользователь может совершить следующие действия при работе с веб-приложением:
* Загрузить изображения на сайт (одно или несколько на выбор).
* Отменить загрузку изображений на сервер.
* Удалить с сервера загруженное изображение.
* Выбрать параметры сжатия (разрешение, глубину цвета, сжатие с потерями или без потерь).
* Осуществить сжатие изображения.
* Просмотреть сжатое изображение.
* Сохранить сжатые изображения на своём устройстве.
# Интерфейс (UI)
Интерфейс должен содержать элементы, необходимые пользователю для загрузки и выгрузки изображений (Drag-and-Drop, экранные формы, кнопки), предпросмотра сжатого фото. Дизайн должен быть минималистичным и обеспечивать удобное взаимодействие пользователя с сайтом.
# Дополнительные функциональные требования (необязательно)
* Сжатие видео.
* Стриминговая загрузка видео на сервер.
* Офлайн работа в режиме PWA на компьютере пользователя.
