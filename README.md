# Краткое описание проекта
Веб-приложение для конвертации изображений в формат AVIF с использованием аппаратного ускорения через кодек AV1.
# Технологический стек
Frontend: React.
Backend: Node.js.
Обработка изображений: библиотека libavif (C/C++).
# Функциональные требования
Загрузка изображений для дальнейшей обработки.
Предпросмотр.
Сохранение сжатых фотографий на кстройство пользователя.
# Интерфейс (UI)
Интерфейс должен содержать элементы, необходимые пользователю для загрузки и выгрузки изображений, предпросмотра сжатого фото. Дизайн должен быть минималистичным и обеспечивать удобное взаимодействие пользователя с сайтом
