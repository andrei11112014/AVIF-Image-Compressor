# Краткое описание проекта
Веб-приложение для конвертации изображений в формат AVIF при помощи кодека AV1.
# Технологический стек
* Frontend: React.
* Backend: Node.js.
* Обработка изображений: WebCodecs, FFmpeg, Sharp, Squoosh.
* Контейнеризация: Docker.
* Сервер: nginx
# Функциональные требования
* Работа в актуальных версиях браузеров:
  * Google Chrome: версия 85 и новее.
  * Mozilla Firefox: версия 93 и новее.
  * Microsoft Edge: версия 121 и новее.
  * Opera: версия 71+
* Работа в актуальных операционных системах:
  * Windows 10/11.
  * Linux 6.1 и новее.
  * Android 12 и новее.
* Работа с форматами PNG, JPEG.
* Загрузка изображений на сервер.
* Возможность сжатия с потерями и без потерь.
* Возможность изменения разрешения загруженного изображения. 
* Возможность сохранения сжатых фото во временный буфер на время работы сессии.
* Предпросмотр готового результата в окне и в полноэкранном режиме.
* Сохранение сжатых изображений на устройство пользователя.
# Пользовательские возможности
Пользователь может совершить следующие действия при работе с веб-приложением:
* Загрузить изображения на сайт.
* Выбрать параметры сжатия (разрешение, качество, степень сжатия).
* Осуществить сжатие изображения.
* Просмотреть сжатое изображение.
* Вернуться к ранее сжатому изображению.
* Сохранить сжатые изображения на своём устройстве.
# Интерфейс (UI)
Интерфейс должен содержать элементы, необходимые пользователю для загрузки и выгрузки изображений (экранные формы, кнопки), предпросмотра сжатого фото. Дизайн должен обеспечивать удобное взаимодействие пользователя с сайтом.
# Дополнительные функциональные требования (необязательно)
* Сжатие видео.
* Стриминговая загрузка видео на сервер.
* Офлайн работа в режиме PWA на компьютере пользователя.
